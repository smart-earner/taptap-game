# 三国小城 · PRD v0.7.2 场景设计册

依据 GitHub main `3f89632` 的 PRD、SLIM_V0_7_2、生活版分章、HUSBANDRY_V2 与 BUILD_STATUS 制作。

在 sanguo-town 目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 http://127.0.0.1:8765/prototypes/prd-v072/ 。请使用 HTTP 服务，以便读取名将配置。

12 个场景：开局、白昼、饭食物流、养殖、夜巡、施工、方针、宝鉴、军团、区域、成长册、桌面。

本原型不连接游戏引擎、不修改存档、不产生真实采购与授权。名将名单和四维读取仓库 spec/heroes-v0.7.2.json；其余库存、发现状态、成长日期为设计快照。场景动画为路径示意，不用作数值验收。

可交互：场景导航、开局时间点、饭食阶段、养殖阶段、施工滑块、方针选择、名将搜索/筛选/详情/心愿、军团授权档位、区域节点、成长对比滑块、动效暂停。支持窄屏、键盘焦点和系统减少动态效果偏好。

已知设计占位：养殖分阶段共用牧栏画面；四条工程复用地图局部；名将为程序化风格头像，兵器坐骑为类别示意；桌面是浏览器合成，并非原生透明穿透窗口。未实现军团、跨城等均在页面明确标注目标设计。
