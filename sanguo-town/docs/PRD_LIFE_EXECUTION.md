# PRD v0.6 开发执行规格：城市生活

2026-09-20。配方版本 life-0.6.0。本文是开发契约，不是所有功能已实现的声明。工时、配方和武将属性均为原创游戏参数，不是现实农业周期或历史人物评价。完整运行状态将独立记录。

## 1. 必须实现的体验与版本边界

全桌面城市，居民白天劳作、黄昏归家、夜间巡更。每批粮、肉、木材和饭菜有来源、执行者和去向；不能旧产率加库存，同时再用动画假装生产。玩家只做方向、重要任命和重大扩张决定，不逐餐喂饭、逐车派单、点击抓贼或领奖。

L1先开发独立城市生活试验档：播种、成熟、收割、运输、碾米、做饭、送餐、就餐、满意度、基础扩建、作息和夜巡。L2接肉食、军粮、全部工业/商业；L3接六将实际招聘与效果、名器/坐骑实物、轻治安事件。未开放模块必须标注，不能用可点击空按钮假装完成。

旧world.json保持不变。新档用Application Support/SanguoTown-Development/city-life-0.6.json。新档不得同时调用旧GrowthRuntime的生产和口粮扣除。L1不提供旧城迁移，不隐式发新资源到旧城。

## 2. 唯一时间、单位与地图口径

1现实秒=1模拟秒。1成长日=86400秒；1生活昼夜=2880秒，即48分钟。不能把作息周期当成长日。晨[0,240)，昼[240,1920)，暮[1920,2160)，夜[2160,2880)。每周期600秒、1800秒分别开午餐和晚餐，延迟供餐缓冲480秒，实际吃饭30秒。

资源为整数标准份，显示袋、筐、桶、份；旧1000毫单位对应1标准份，但本批不混档。配方整批生产；工时除法向上取整；不得截断产物凑容量。帧率、画质、屏幕大小、观看频率不进入资源公式。

地图制作参考1920×1080逻辑单位，按屏幕等比适配，剩余补郊野。全屏是桌面层，不是独占全屏App；普通工作窗口和桌面图标在前，鼠标穿透，不读取文件位置或其他工作窗口。主要工作点避开菜单栏/Dock。

标准显示96人、省电48、丰富160是测试预算，不是性能保证。真实人口不足不生成假工人；模拟上限每城256人、活动任务256、待办512。动物另限24个可见实体，车是搬运者附件不是新劳力。桌面15fps/省电8fps为目标，M4能耗另验收。

## 3. 开局精确定义

开局16名成年普通居民，500铜，16住房位，没有收藏名将；宋宁是居民之一，兼代理太守、五维均50。岗位：代理1、农夫2、伐木1、汲水1、碾米1、厨师2、挑夫3、营造1、铁匠1、仓吏1、昼守1、夜巡1，共16。L1铁匠只研习/休息，不伪造铁器产出。

总仓：48粮、36木、12石、6铁、24水、4器材、4种籽；稻田料场1种籽+6水；菜田1种籽+3水；里坊公共食堂32份家常饭。其余0。只创建一次，读档不能补送。

基础设施：府署、里坊食堂、两田块、田边料场、井、林地、总仓、碾坊、饭馆灶房、营地值守点。矿点、猪栏、铁坊有位置不代表已营业。初始图鉴显示未拥有的六将与前置，不把人头像出现当招募完成。

第一份普通图录“乡里第一餐”：首次一餐结束时本餐登记居民全部吃饱后自动获得，仅纪念、不发钱粮。最早第10分钟开饭后得到，晚送则更晚；失败顺延，不定时白送。独立于六器四马，不冒充名将奖励。

首段里坊扩建一次：40铜、12木、6石到工地齐备，营造人工600秒，完成+4住房。没开工不增人口，不能反复重建刷经验。两次连续足量供餐、满意度≥65且有住房时，每餐后最多迁入1普通人，不赠随身资源；新来者从下一餐计算。

计时从播种人工完成开始，自然生长不占人、跨夜继续；成熟只变“可收割”，不自动入仓。实际收割完成才在田边生成一批。料场容量不足先等待，不毁掉半茬。每田同时一茬，收完才能重播。缺水种籽不半扣材料，已播作物不每秒重复扣水。

水稻后续：每趟至多8谷到碾坊；4次“12谷→10粮+2饲料”才把48谷变40粮8饲料，总碾米人工240秒；运输、通勤、休班另算。32.5分钟不是从田里到饭桌总耗时。

改种是待下一茬的决定：当前茬保留已消费原料、成熟时间和品种，不能改种立即重置产出或退资源。L1新田默认水稻和青菜。

## 9. 供餐、满意度、食物分流

每餐开始固定登记当时在城居民ID，不在城军人不重复算本城餐。饭先由人送home食堂；居民完成安全工序后前往，开始就餐预留一份，吃30秒后消费/记该餐已吃。先肉菜饭、后家常饭，家常饭足量就是正常生活。home没饭不能凭总仓粮判已吃；画了几张桌子不限制模拟席位。

C=已吃/本餐登记，Q=肉菜饭人数/max(1,已吃)。目标满意度=clamp(70+floor(40×(C-1))+floor(10×Q),0,100)。实际每餐最多下降8、上升4；初始70。整数实现：coverageBP=served×10000/expected，qualityBP=hearty×10000/max(1,served)。零登记保持旧值。全基础饭目标70，全饿目标30，一餐只从70降至62，不一次崩城。

餐在480秒缓冲后结束，每餐只能结算一次。迁入不补扣来之前的饭。满意度<65暂停新增迁入；L2<50可使可选工业/非必要训练工时最多+20%，农业、碾米、做饭、取水和运输不受罚。L1只影响迁入，不暗加惩罚。恢复供餐自动恢复满意度，没有死亡/暴乱/永久离开/逐户安抚。

分流顺序：当前及下一餐→民用安全储备→已承诺在途军务→种养循环→基础建设→改善菜单→新增扩军/远征→酿酒出售收藏。备战不能绕过民食底线。居民吃公共饭不产生国库收入；外来人买饭必须有真实需求、实际餐食消耗和付款。

## 10. 昼夜与轻治安

普通工作只在晨昼启动；预测路径+人工能在暮末2160秒前完成才开工。否则不扣材料，次日继续。已携带货必须交完再回家，不删货、不瞬移。自然成熟跨夜。夜班只是夜巡岗，不把同一人24小时重复排班。

夜普通人回home休息，夜巡提灯走营地-总仓-城门。光照晨0.55到1，昼1，暮1到0.35，夜0.35；只作用游戏层，不遮黑用户整张壁纸。居民在家仍保留实体。

小贼L3每第4、9、14…周期夜出现1次外部小事件，120秒完成接近/被巡兵驱离/离开。无损失、无点击奖励；没巡兵记巡视空档，不编造抓捕战果。事件以周期和存档ID确定，不依赖开窗抽随机数；不把低满意居民当罪犯。
