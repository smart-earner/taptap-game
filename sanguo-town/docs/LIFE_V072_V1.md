# life-0.7.2-v1｜第一段可玩的城市生活

## 先打开正确的窗口

应用顶部菜单栏 → **城市生活 · 新版试玩** → 首次接受默认保供。这里有“我的城”“武将宝鉴·30”“城务记录”。其他旧主公府/城市概览仍使用原来的存档和规则，不要用它们判断新生活版。

新生活窗口里的“铺满桌面”使用整块选定显示器的桌面层：工作窗口在前、鼠标穿透。想查看某个居民时回到普通生活窗口点击人物，右侧显示职责、当前动作和实际携带物。新桌面大小按屏幕适配，人物数量来自实际居民，不强行补到96。

首次看到的是16名真实居民，不是30名武将同时入城。荀彧为初始太守，其他人种植、搬运、做饭和修缮；夜巡白天休息。很多人可能在同一住区、设备或等待点，当前空间分散与美术仍需打磨，不能把人数当观感验收。

## 一批粮怎样成为饭

默认第一块田有来自开局聚落的在长粟，剩余约360模拟秒成熟；成熟后等人收割，粮袋先存在田边。搬运工装货时源库存减少，途中货物仍有批次，卸完才进入目标库。厨房需要粮和木材实际到输入点，厨师到岗后投入，炊煮释放厨师但占灶，收尾后才出饭。堂食/住区餐点实际收到并由对应居民消费，餐次不能重复结算。

公用水井在本版是灌溉的可达服务点，不是第9种库存。厨师不因为舞动锤子或窗口播放一帧就多产饭；关闭动画或屏幕不会改变模拟产出。

## 目前值得看的成果

府署四阶段修缮、住房扩充、集市、工造院和饭馆陆续形成；输入材料要实际搬到工地。你可以授权开城木印，它消耗10铜、2木与360秒有效木工作业，完成后在府署外陈列。受其他任务与饭点影响，实际完成时间不保证10分钟。

首次真实收获会发现赵云；宝鉴可查看30人的政治、智力、武力、统率和技能。选定已发现人物后，确认整条招募预算，普通阶段自动执行。材料/床位不足会等待，未发现的前置条件直接显示。当前已有30套数据和通用流程，不代表所有建筑前置都已开发；尤其商路渠道所需驿站等仍待接齐。

已加入人物在空闲时可任太守；收益由通用属性和适用技能解析，已经开始的任务不追溯更改速率。没有每天加点、洗练和点击领奖。不是30名人物各写一条姓名特判。

## 存档与安全

生活版保存：`~/Library/Application Support/SanguoTown-Life072/world.json`。原存档目录`SanguoTown-Development`不自动迁移；两者是两个独立试玩世界，而非同一个世界双算资源。只有打开旧版入口，才启动旧会话。

生活存档带完整性检查和三份备份。校验失败显示错误，不悄悄清城。完整备份恢复界面尚未制作；原型格式不承诺以后无提示自动迁移。退出前保存失败会阻止正常退出并显示原因。

Mac开发包最低macOS15、Apple Silicon；仅ad-hoc签名，未公证。不要通过关闭系统安全保护来运行。可以在有Swift6/Xcode的Mac按README本机构建。

## 接入方式与复核

`Sources/SanguoLife`不依赖SwiftUI或SpriteKit，负责时间、任务、资源、餐食、施工、招募与持久化。`SanguoLifeVisual`只读投影；Mac窗口和CLI回放共享造型与位置。已有town-0.5核心保留，不把其旧产率偷偷叠进新资源。

生成配置：`python3 scripts/export_life_catalog.py --check`。
运行新增测试：`swift test --filter LifeTests`。
运行整套回归：`swift test`。
单城一天：`swift run -c release SanguoLifeCLI --seconds 86400 --cadence 120 --seal --output dist/day1`。
查看真实时点：在上条命令增加`--preview`，输出HTML不是实机录像。

本批先把采收→搬运→烹饪→消费和一次城建/收藏接通。它不是全部PRD的完成版：养猪、完整战争、骑乘、装备、多城、全部特色路线、原生UI实机体验以及90日内容仍需继续开发和验证。
