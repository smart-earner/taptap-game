# 五将试玩 preview1

基于 GitHub main `0259545` 的原生 Swift/SpriteKit 代码，不是 HTML 替代实现。

## 运行

在项目根目录运行 `bash scripts/build-hero-preview.sh`，打开 `dist/SanguoTown-HeroPreview.app`。
默认开局为荀彧、刘备、张飞、赵云、黄月英，分别偏好做饭、种田、采木、搬运、营造。人物可互相支援；右栏可调整偏好，当前工序不取消。

“演示推进60秒”会真实推进生产、消耗和工程，并保存，不是纯动画快进。正常运行仍按现实秒推进。

## 已接入

- 五个唯一武将实体、差异化矢量外观、当前任务和可调劳动偏好。
- PRD bootstrap 400铜、5床位与初始八资源数量；基本饭配方1粮/0.25木→4饭。
- 真实田间收割、资源搬运、做饭、送餐和消费、600人工秒府署修缮。
- 荀彧实际处理城务后获得600秒治理租约，夜间无加成；同一人物不同时作为自己的领导加成来源。
- 独立规则标识 `hero-town-0.8-preview1`，独立存档 `~/Library/Application Support/SanguoTown-HeroPreview/world.json`。不覆盖旧存档。

## 明确未完成

不是完整0.8验收版。暂未开放新版招募、扩建、养殖、调任；地图沿用旧布局。六类工作组、完整行政/休息预算规则、招募抵达流程及30将完整独立美术尚未实现。旧图鉴属性仍沿用原参数库；不代表所有0.8数值均已落地。勿将试玩存档标为正式0.8格式。
