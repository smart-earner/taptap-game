# 桌面三国·小城志 · PRD v0.7.2

## 首版收敛：8种物资、30名武将

**这是新生活版的研发范围修订，不是客户端更新。现有运行版本仍为town-0.5＋desktop-0.1。**

城市长期成长、玩家只作重要决策的定位不变。现将尚未实现的17资源方案收敛为8种可堆叠物资、2种作物、4项加工；首批武将内容池由6名增加为30名。沿用四维、22技能与7效果原语，不增加24套人物例外。开局仍荀彧＋15居民。

## 当前规范与数据

- **[v0.7.2收敛规范与完整30将表](SLIM_V0_7_2.md)**：资源去留、配方、服务化用水、成本替换、饭食、种养、名单、招募模板、范围与迁移禁令。
- [首版范围数据](../spec/slim-v0.7.2.json)：8库存、2作物、4配方、设计报价转换、旧基线校验值、禁止扩展项。
- [30将配置](../spec/heroes-v0.7.2.json)：四维、1—5技能、建议用途、发现条件和六个标准招募模板。
- [配置生成器](../scripts/build_slim_v072.py)与[配置/参考测试](../scripts/test_slim_v072.py)：从锁定的0.7.1基线生成四份有效配置，不读写用户存档。
- [四维与通用技能公式](life-v0.7/06A_ATTRIBUTE_AND_SKILL_SYSTEM.md)：本次不改技能规则；旧章中的“六将”数量由30将表取代。

**运行实现应加载生成目录resolved中的life/content/bootstrap/hero-system JSON，不直接混用旧spec与新表。** 旧life-v0.7.json等四份JSON仍保留原字节用于确定性构建输入；数量、配方和招募在生成时按本次规范统一替换。基线校验值变化时构建拒绝，不由开发任选一套。
