# town-0.4｜持续街区与城市经营集成

此版本把原先独立检查点接入实际 Swift Package。定位仍是开发版，不是全部 PRD 功能或发行验收完成。

## 玩家现在能做什么

首次打开选择长期治理；旧存档启用新版规则需要明确确认，不删除已有城池、人物、库存。默认窗口仍是看城，详情集中在主公府的可展开区域。

- 太守在原有建筑建设之外持续安排八类街区工程：街巷、水利、里坊、商街、工造、书院、园林、城防。工程共享施工劳力、占用真实材料与预算，暂停不清零，完成才产生对应效果。
- 同视角城景增加石路、灯柱、沟渠、水井、桥梁、院落、铺面、堆场、树木和箭楼；完成等级决定增量，当前施工只有材料与进度，不提前显示全部已完工景观。
- 成长册保存真实历史街区状态，可切换已拥有城市，移除手动固定快照不会影响资源；自动里程碑保留。
- 16条常驻收藏目录（6人物、6兵器、4坐骑）有列明的现金、材料与工时。一次批准当前心愿，步骤自动推进；已付费步骤不因切换心愿消失，获得后停止而非自动换下一件。
- 名器与坐骑可登记配备，唯一物品不能同时借给两人。城景武器暂映射基础长枪或佩剑；坐骑骑乘和各名器专属美术未完成。
- 空闲人物自动研习；人物跨城先交接再旅行，在途不能担任两地职位，也不在两座城同时显示。
- 地区合作、贸易和新城接纳需玩家明确批准；已有城市持续运行，不要求每天响应。可以建立一个辖区，在授权人才池中自动任用已抵达当地的太守。

## 必须区分的实现边界

| 模块 | 当前真实实现 | 尚未声称完成 |
| --- | --- | --- |
| 街区 | 8轨×3级、劳力与预留、真实可见增量 | 完整美术、每个城市独有风格、无限后续内容 |
| 运输 | 有限运力、城市粮食援助、渡口酒出口、到达与返程 | 所有商品通用贸易界面、完整路线风险模型 |
| 山地合作 | 合作后当地铁料采购优惠 | 独立铁料进口运单 |
| 新城 | 预付合作合同，到期交接基础资产和代理太守 | PRD逐车安置与现场建城过程 |
| 军务 | 已批准军团的护送开路、有限强度检验、伤兵恢复 | 三路战场、完整回放与各武将战术 |
| 人事 | 任太守、建辖区、明确跨城调任、空闲研习 | 自主跨城选拔完整计划、培养树、重划辖区 |
| 收藏 | 列明阶段成本和永久实例、人物实入城、装备唯一 | 每件物品的专属故事美术、骑乘动画、全部装备数值效果 |
| 现实联动 | 无 | 按键与行情模块仍未接入，未采集工作数据 |

## 已修复的问题

开局立即追求人物时，收藏与建设可能耗尽第一座集市所需现金；新版保留建立销售渠道的资金，避免零收入停滞。其他修复包括公共工程纳入统一预留校验、在途人物禁止任用、运输容量不与生产输出双占、地区结果只读出发快照、历史城景不读取当前街区。

## 长周期结果的正确解释

新 town 规则的45个检查点覆盖5种方针×3种查看间隔（1/3/7日）×30/60/90日，固定同一初始授权时状态一致。均衡样例街区改善分别10/17/22项；人口80/84/88；军团批准60且未追加，现役不会超过60。

这是加速的确定性运行验证，不是连续真实试玩90天。后期现金仍明显积累，多个方针的最终建设可能趋同；平衡与特色差异还需继续迭代。不能用测试数量或运行天数代替好玩程度，也不通过隐瞒限制宣称PRD全部完成。

## 构建与验证

```sh
cd sanguo-town
swift test
swift run SanguoGrowth --town --matrix --output dist/town-matrix
swift run SanguoGrowth --town --days 90 --cadence 3 --legion 60 --output dist/town-preview
# macOS / Apple Silicon，Swift 6 / Xcode SDK：
swift run SanguoMac
bash scripts/build-macos.sh
```

新旧规则选择明确：省略`--town`仍运行旧growth切片，不能误把旧结果当新规则证据。macOS SDK测试与打包不代表M4窗口、多屏、能耗、长时间睡眠体验已经实测。开发包只作ad-hoc签名，不是已公证发行包。
