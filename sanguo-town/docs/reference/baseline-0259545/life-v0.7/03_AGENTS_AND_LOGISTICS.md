# 03 武将实体、偏好、作息与物流
**PRD v0.8.0；不再有普通居民和永久20岗位配员。**

## 3.1 身份和职责
Resident必须有heroID，且属于30将目录；heroID全世界唯一。初始5、招募最多30。origin只有founding/recruited；禁止immigration。访客有visitorID与来源合同，不能作为resident worker传入。每人一位置、一床、一独占activeTask，携货与旅程计在同一实体。
玩家看到6类偏好，后台保留20工种以复用明确属性权重：
- food：farmer、cook、server、herder、butcher、rationer、groom
- supply：logger、miner
- craft：carpenter、smith、builder、restorer
- logistics：porter、clerk、courier
- trade：merchant
- guard：guard、quartermaster、handyman
四维、技能引用和默认偏好逐人见06章JSON。所有武将具备全部基础生产资格，特殊技能不是门槛。偏好prefer只影响同优先任务分配，不产生倍率；automatic无偏好；rest_optional不参加可选任务但仍自动承担必要保供。换后台工种15有效工作秒，同工种连续任务不收；换偏好不退款旧换岗劳动。

## 3.2 调度确定算法
每30秒及重大完成/餐窗/班次事件规划同一revision快照。先固定已开始安全阶段；空闲可用人物匹配真实任务，绝不创建假订单保持忙碌。
任务优先级：0已携货交付/安全收尾；10餐窗与必要供餐；20灌溉/收割/基础原料；30已购动物照料与必要维护；40行政；50已授权施工/器材/招募接待；60菜单改善/清扫/守备；70外贸/收藏；90研习；95闲居。
同优先按deadline（无截止取Int64.max）→createdAt→orderID。每任务先过滤资格、路线、班次、休息可行、锁定/在途；同优先已接受任务不抢占。候选排序为预计到达时间升序、prefer匹配降序、A_job降序、heroID升序。rest_optional过滤priority≥40，但必要维护≤30不屏蔽；行政可由另一个实际授权代理执行，无法执行就无租约。
至少2名在城可排班人物不得被priority≥40的长任务占用；这是可用集合保留，不是永久2挑夫。人数<2进入安全保供，仅顺序必要任务。一城可选工程并发1、最多2施工人；父单最多2048，每轮新增父≤8、子≤32，consumerKey合并。
厨师可取料、农夫可收后自运；只有到设备时才可开加工，WAIT_INPUT不占人。必要任务180秒无进展给证据诊断：过期未开预留释放、改最近合法来源、把可选人释放到安全点；不能打断已在制批次退料。

## 3.3 作息与行政
cycle=2880秒，growthDay=86400秒。晨0..240、昼240..1920、暮1920..2160、夜2160..2880。日班可接新单240..1920；必要服务0..2160；暮间安全收尾返家。每人每周期人工+通勤+装卸+换岗≤1920秒，预测任务完成加返家必须≤2160且保留夜间连续600秒休息；不可能完成则等待下一班。
必要餐食可占用日间未安排劳动，不得借紧急无限延长劳动上限。出乎预测的已携货仍安全交付，记录加班/休息失约并优先修复，不瞬移。
太守是职位，不是永久占满的工种。每周期phase0开始，每600秒产生一次30秒行政任务；同一时刻只保留最新未开始的一单，不补做全部过期单。实际完工后组织租约expires=completeAt+600；夜间不生成/延续行政，入睡立即失效。太守可在租约期顺序做别的工作，组织效果是已完成管理的有限结果，不新增劳动时间。行政按handyman权重；自身不领取自己的主管属性/组织技能，其他本人适用技能照常。
5—7人无夜巡且无罚损；8人以上可排最多1段120秒实际守备巡线，安排在phase2040..2160并含去回程；剩余时间不够则不发单，全部回家。不是一个人整夜游走。晚间只留灯火与休息演出；无巡线治安基值仍60。

## 3.4 人工、经验与被动等待
A_job与技能见06A。workBP=baseSeconds×10000；每段扣dt×rateBP，完成ceil(remaining/rate)。新阶段/换工组快照，不每帧舍入。被动成长不吃人工率。
每300有效人工秒1XP，余秒保存；阈值0/60/180/360/600为L1..5。装卸/施工计、空走/等待/演出/睡觉不计。研习120秒、每cycle至多1XP且24小时最多10XP，priority90，不提升基础四维/技能等级。

## 3.5 运输全链路
货物只在sourceStock、carried、destinationStock、WIP、consumed之一。sourceReserved为stock子集。预留出库与入库同事务；装货减源加携货，卸货减携货加目的；同资源搬运总量守恒；转配方按输入输出核销，禁止总数量混加当守恒。
空手48地图单位/秒，肩挑32、板车28；容量4/12体积，一趟一种resource、meal还必须同quality。装10劳动秒、卸10劳动秒；无可用仓吏，承运者验收入仓另10秒，不另造仓吏。设备/住屋卸货不额外仓验。
量mU=min(缺口,sourceFree,floor(剩余载体积/系数),floor(目标剩余体积/系数))。支路走图，长度ceil(距离×1000)，行程ceil(length_mMap×10000/(baseSpeed×1000×speedBP))。每段开始快照；无路等待、不穿墙。来源按本设备→同建筑→本城最短可达→已授权外购，等距locationID。
黄金：有仓验人员夹具，源8粮、装4、负重路960，t10源4携4，t40到达，t50目的4；t49不能吃。若无人仓验则t60才能入仓，人物贡献劳动照计。
目的失效改兼容最近仓，否则返源；源满进本批容量的返货缓冲，只出不进不作永久仓。未装可取消释放，已装只安全交付或返源；加工已开始只暂停/续做，完成重放返回原receipt。

## 3.6 同时刻顺序
按(timestamp,priority,sequenceID)：劳动/被动完工→卸货与外部结算→班次/行政失效→餐点名单→餐窗截止消费→满意度→招募到任→机会→规划。截止同刻卸的饭可吃；同刻到任从下一餐计。相同种子/命令轨迹，不同渲染和分段推进须世界规范化JSON一致。
