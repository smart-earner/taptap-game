# 08 全桌面地图、武将生活与Mac交互
**PRD v0.8.0。独立角色和少人数镜头是本版必需内容，不是后补换皮。**

## 8.1 桌面承载，不是独占全屏

默认目标为选定NSScreen.frame整张桌面层，保留系统壁纸、不压普通工作窗口、无需创建独占全屏Space。主要交互仍在菜单栏和普通可交互视图。桌面层鼠标穿透、不成为key/main窗口；无输入监控、辅助功能、壁纸读取、桌面文件扫描或录屏权限。公开窗口层级与系统Spaces行为须实机验收，不保证系统版本间绝对相同。

一个GameSession与一个模拟时钟；同一城市可有桌面与管理视图，但不会多算产量。多屏默认只显示选定一屏；断开则临时回内置/当前主屏，保留原屏ID重连恢复。设置缺失或损坏回退普通窗口，不重新建档。用户隐藏/退出只撤动态层，不重设壁纸。

## 8.2 世界坐标与工作点

参考世界1920×1080，坐标原点左下。经济路径使用地图单位，不随Retina像素或窗口缩放变。核心点映射进visibleFrame（避开菜单栏和Dock），郊野背景可以延伸到screen.frame边缘；主要单位不被安全区裁切。

默认s=min(可用宽/1920,可用高/1080)，居中保持比例；多出来区域扩展草地/水面/树景，不拉长人。人物参考38单位，目标不小于22点；s不足22/38时切换可设置的关注区域镜头，不通过偷加人口或减少路程解决。全景与关注区域都是同一世界不同相机。

稳定slotID与新布局中心：
0府署(1060,760)；1民居(910,760)；2民居(770,750)；3民居(920,930)；4农庄(570,730)；5粮仓(560,550)；6集市(910,550)；7工造院(1370,540)；8饭馆(1060,550)；9马厩(1540,470)；10驿站(1460,290)；11营地(1610,740)；12民居(1080,930)；13粮仓(580,930)；14农庄(570,470)；15工造院(1370,790)。新layoutVersion=5；老照片保留原版本，不交换资产ID。

建筑地面碰撞盒中心左右45、向下22/向上28；屋顶可高于此盒，屋顶遮挡不意味着不能走。入口在中心(x,y-28)，连接最近可行水平主路。主道路纵x={140,680,1200,1780}、横y={200,380,640,840,1000}形成20交点与相邻边；支路投影加入同一图，不用每人自行走直线。

24田床为4列6行：x={210,285,360,435}，y={260,330,450,520,720,790}，固定入口连接主路；先启用农庄容量内的床ID。林地(300,930)、井(740,550)、矿点(170,140)、采石(390,140)、城门(1560,200)。树24个子节点围绕林地生成，树干不占主道路。主路穿河处是开局已有小桥，记录基础设施来源，不要求先过一条不存在的桥运造桥材料。

配送点候选：(770,810)、(950,810)、(1040,980)、(810,930)，分别服务四住区。工坊/灶/堆料/马位是建筑院内subNode，不生成额外功能地块。任一自动支路与碰撞盒相交则拒绝布局配置并报错，不能允许引擎直穿建筑；单测必须遍历所有源到仓、厨房、住宅和工地路径。


## 8.3 五人开局与人数表现
默认关注镜头worldRect=(430,450,1050,600)，覆盖农庄/粮仓/官署/住宅/厨房；5—7人不默认用整张空地图。用户可切全景或跟随任何真实武将，镜头不改路程、不移动建筑。达到8人仅提示可扩展视角，不强制缩小角色。
常住最多绘30，临时访客4，动物6（2猪4马），人数不足不补假人；窗口遮挡/视野裁剪不暂停经济。全景人物至少22pt，缩放不足则提示关注视角而不是放大地图收益。
桌面默认15fps、省电8、查看30；关闭动效只暂停绘制。系统减少动态效果关闭呼吸/飘字/相机平滑，保留瞬时状态与文字。夜色只作用游戏图层，不给壁纸罩黑幕。
少于8人无整夜巡兵；8人后最多一位短段晚巡，2160前返家。已回家不继续在街上画另一个夜巡替身。寝居可亮灯但室内剪影必须引用真实居住者。

## 8.4 人物资产与动画合同
每位heroID必须有唯一artDefinition：silhouette、palette、head、outfit、portrait、idle/walk/work/rest引用，至少3项形体/装备/动作差异；不能30个同形小人换文字。先完成5开局资产验证，再扩其余25；原型占位必须明示，不算完成。
开局辨识：荀彧文士冠/青衣/竹简；刘备朴素长袍/草编/舒缓步态；张飞宽体短须/扛料；赵云浅甲/轻快配送；黄月英工具包/图纸/测量。诸葛亮羽扇、关羽长须绿袍、鲁肃账册作为后续明显轮廓。
工作表现只能由真实task.stage驱动：
- 农事：种具、井边取水服务、浇灌、镰收；成熟才有田边粮袋。
- 供料：斧/木捆/幼苗、矿镐/石筐/铁料；无旧矿石熔炉演出。
- 运输：实际装载后出现货，卸货后空手；木、粮、肉、器材、餐盘有不同形状。
- 炊煮：PREPARE备料、PASSIVE冒汽、FINISH装盘；PASSIVE厨师可离开，不能同时站在两个设备。
- 施工：清场/立柱/上梁/收尾四阶段对应实际百分比；等待材料不画继续施工。
- 养殖：2头有animalID、6段体型、牵入/照料/关门加工/肉筐；马永不产肉。
- 生活：真实居所休息/同席/短谈，07章故事15秒且不阻塞经济。
人物动画不生成劳动，携物按lot量显示至少一个完整/半份图示，不能靠图标数量记账。实际搬不到的武器不出现在人物手上。

## 8.5 信息层级与交互状态
默认桌面穿透，入口“看看我的城 / 武将宝鉴 / 发展方向 / 成长册 / 显示设置”。
看城最多三行：正在做、接下来、最近完成。选人打开右侧轻详情：姓名/头像、当前任务与阶段、下一节点、携货批次、住处、偏好。二级展开四维、技能、有效来源、劳动率、班次和具体等待原因。
偏好控件 automatic / prefer(6类之一) / rest_optional；显示“必要生活仍自动安排”。提交前显示只影响未来分工，已有携货先交付；成功由世界回执驱动，失败不乐观显示已改。
建筑四列“生产/发运/到货/实际消纳”，未接引擎页面明确演示，不拿仓库总量当厨房现货。选择目标显示缺口、预计最短工时/等待，不保证墙钟完工。
宝鉴30将四态，5起始已拥有，25候选条件逐项可解释；搜索按姓名/职责，先显示角色不是抽卡稀有度。一个心愿与三个关注可切；军团专用技能标当前无作用而非假加成。
主要错误有可恢复下一步：NO_BED看住宅；NOT_DELIVERED看批次；OUT_OF_SHIFT看下一班；NO_CASH看预算；FEATURE_DISABLED明确版本范围。不把全部失败合成“请稍后”。
键盘支持Tab/Enter/Escape，焦点不被实时刷新夺走；文字对比至少4.5:1，任务状态不能只靠颜色。悬停名称不强制所有角色永久顶着标签。

## 8.6 桌面工程与体验门槛
默认鼠标穿透，不抢key/main，不需要辅助功能/录屏权限；多屏仅选定一屏、断开回主屏、重连可恢复选择；同世界多视图不双算。
保存失败保留原城，不用空城代替；未追赶完离线可看最后快照但标明恢复中，写命令禁用。隐藏/睡眠不补播几天演出，恢复定位当前真实状态。
5位开局、其余25位、六兵器四马、10类建筑、4条工程均需独立美术验收；允许分阶段预览发行，但不将占位叫完整版本。用户无姓名提示能区分开局至少3人、说明一人当前工作；完整日夜看懂返家和短巡，不出现假劳力。
