## 一、产品目标
常住居民全部改为具名三国武将（包括文臣、谋士），每人唯一。用少人数、可辨人物、真实工作、居所和相遇故事建立陪伴感；不再用无名居民增长制造热闹。玩家决定方向、人物工作偏好、一次招募/收藏心愿与重要工程；无需逐餐、逐车、每日排班。

## 三、已确定的实现选择
- 开局五将：荀彧、刘备、张飞、赵云、黄月英；首批30将全世界唯一，其余25人可招募。
- 单城、最多30常住武将；不存在普通居民迁入。四栋住宅床位5/8/10，空床不生人。
- 五人能顺序兼岗；太守行政需真实30秒劳动，完成后600秒组织效力，不永久锁住一位劳力。
- 家常/肉菜/军粮改为4份一批；食粮与木材按原转换比例，八资源不扩表。
- 军团、跨城与新城不属于 v0.8 发布范围，功能开关固定关闭；后续保留方向，不拿旧90兵或三城模型充当新设计已确定的内容。安远营在本版为名将守备与物资训练场，不生成无名兵。
- 原生现状仍 life-0.7.2-v2，已有246项旧回归不是 v0.8 成绩。HTML原型尚未同步本轮人物改版。
