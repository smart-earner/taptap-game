# PRD v0.7.2 · 首版收敛与30名武将

**交付类型：范围修订、可生成的有效配置与人物目录，不是新客户端。** 当前软件仍为town-0.5＋desktop-0.1。本稿把尚未实现的生活版从17种资源收敛到8种，把人物内容从6名扩为30名；不把30人名单等同于30张美术已经完成。

## 1. 本次决定与版本权威

第一版固定8种可堆叠物资、2种作物、4项通用加工配方、30名武将、22项既有技能、7种既有效果原语。铜钱独立记账；人口、满意度、许可、经验和建筑等级是状态，不是新物资。

这是对0.7.1的定向覆盖：资源/农业/配方以本稿及slim-v0.7.2.json为准；人物/招募以heroes-v0.7.2.json为准；四维公式、技能定义及作用域沿用原06A。旧17资源/6人物JSON保留为受校验的构建输入，不再直接作为首版运行配置。新增武将不得内嵌人物专属effects。

执行build_slim_v072.py产生四份resolved JSON；运行实现应打包这四份有效配置，不能一半读旧配置、一半读本表。脚本检查输入SHA-256，基线被人修改时拒绝生成，必须审查后更新。价格转换仅用于尚未签订的设计报价，不是旧存档资产兑换规则。生成结果目标rules=life-0.7.2、schema=7；没有宣称该规则已接入Swift。

本稿覆盖原第02章的库存与加工，第04章的餐食品类与保护等价，第06章的人物名单和对应获取数据。城建/收藏/地域成本按本稿明确的材料映射重算，最终以resolved为准。其他任务幂等、昼夜、岗位权重、低频决策、任职、既有设备容量和真实施工等未变规则仍按0.7.1相关章节。发现交叉冲突先报规格缺陷，不能自选规则。

厨房和制粮点开工前需有可达井；首版不模拟每锅的桶数和独立取水运单。准备/收尾中的取水可作为既有人工段的动作，不另计经验或再收费。井不可达就报服务不可达，不伪造缺少一个已经删除的water物资。量化供水能力是延期项，不新增暗中的“水服务券”。

资源必须实际运到工作点。被动炊煮/烘干期间释放人工但占设备。生产由消费订单拉动，不无限制作饭菜，也不把本地居民吃饭当铜钱收入。没有肉或肉价不合适时自动改家常饭，不因缺肉挨饿。

木印、板车、兵器修复和活猪出栏是既有唯一物/动物/工程任务，不算新增可堆叠加工配方。它们的输入仍必须是八物资之一，不给它们另开一套资源引擎。

## 5. 农业、养殖与日夜

两种作物均用既有EMPTY→播种→第一次灌溉→半程生长→第二次灌溉→成熟→收割→待运状态机。成熟后不腐烂。水资源取消，不取消真实农夫和劳动步骤。

|作物|播种劳动|有效生长|每次浇灌劳动|收割劳动|净产出|
|---|---:|---:|---:|---:|---|
|粟|45秒|3600秒|20秒，共两次|60秒|食粮16|
|水稻|60秒|7200秒|20秒，共两次|90秒|食粮36|

农夫的浇灌任务路径包括自身位置→井→田床，再做20秒灌溉。桶是该服务动作的持有道具，不建立库存单位或一个可重复交易的lot。播种准备确认井和田可达，无路等待；两次灌溉分别幂等。上述生长/劳动表不包含步行、排班和等待。移除脱壳后水稻吞吐变化属于重新调参点，不能沿用旧产能参照宣称已平衡。

普通猪仍需已建牧栏、已付款幼猪和真实牧工；6段×2880秒有效成长，每段食粮0.25＋照料30秒，总1.5食粮和180秒人工。牧栏放牧与可达井是服务条件，不再独立补草和买水。加工90秒消耗该猪，得到8肉料。缺供安全等待，不死亡、不自动卖珍稀马。收藏马每周期食粮0.25＋照料30秒，缺供暂停下次移动加成、无欠账；驯养阶段一次性投入按报价映射，过程不重复扣常规照料。

48分钟作息、两餐、夜巡、离线补算继续沿用。减少资源不意味着昼夜只换滤镜，也不意味着白天的实体任务退回按小时自动加库存。

## 6. 相关成本、保护线和旧数据处理

生成新的设计报价时：木构每1份替为木材1.5份；酒每1份替为食粮1份；草料每1份替为食粮0.25份；原水投入移除。原料转换按mU逐项向上取整再与已有同类投入相加。猪与饭菜配方以本稿专表为准，不机械套旧方。肉菜质量成本与水利服务均需重做供需仿真。

例如新建民居原报价木12/木构4/石4/器材1，改为木18/石4/器材1；铜120、人工3600不变。全部建筑、院内设备、街区、特色工程、武器、坐骑、区域合同与建城包均由脚本转换，不让开发逐表猜。

工造特色第二段的旧熔炉奖励改为“锻造棚，锻造席＋1”；第三段只加修复席＋1，不再重复附赠锻造席。基础木作席仍用于真实木印和板车任务。第一版没有熔炉升级、酒槽升级或独立水货架。

民食等价E=民用饭菜＋可合法用于民用的军粮＋4×民用食粮＋已投入民食WIP的合法最终人份。每批只计一次，在途按归属计等价但不是立即可食用；军事封存和外卖已售批次排除。底线继续4N，已生产肉料不冒充主粮等价。菜单目标：安民肉食50%，兴商/均衡25%，兴业/备战0%，其他为家常；这是自动改善目标，不是保证与新强制需求。低满意度不重罚农、厨、基础搬运。

新开局仍16人=荀彧＋15居民、铜600。食粮64、木40、石12、铁6、器材4、饭32(basic)，其余0；删除原初始水和草，不另补钱或粮。分庫、床位与起点从原bootstrap转换，32份饭仍在住宅/府署的消费者容器，不重复放厨房。

这只定义全新生活存档。当前正式原型旧存档保持原规则，迁移开关关闭。本脚本从不读Application Support、用户world.json或背包；禁止把本稿的设计兑换率套到玩家旧资产上自动清理或发财。真正兼容迁移另做预检、备份和验收后才允许开启。
