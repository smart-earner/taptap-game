# 05 太守、都督、持续授权与区域协同

## 5.1 权限矩阵

|行为|主公|太守|都督|
|---|---|---|---|
|确定城市/辖区方针、重要锁定|可|只能执行|仅在主公给定城市与方向范围内|
|普通生产、配送、基础恢复、已许可土地建设|可干预|本城可|辖内可协调|
|改普通工种|可|本城按班次自动|不越过在途任务和城市最低岗位|
|任免太守|可|不可任自己的上级|授权talentIDs内可，须交接旅行|
|任都督、重划辖区|可|不可|不能自扩权；重划由主公发命令|
|锁定人物/地块/唯一藏品|可|不可解除|不可解除|
|新增军团、扩大编制、外出目标、新城|可|不可自批|可提案，不可默认批准|
|当前收藏心愿及路径总投入|可|执行已批准阶段|不可擅改心愿|

官职和方针持续有效，无8小时/每日续约。专项合同有总预算、目标、次数和结束条件。上级授权不能被下级创建新名字的专项绕过。

## 5.2 默认主公决策

保留安民、兴商、兴业、备战、均衡五方针。另有不强迫设置的holdPopulation与holdExpansion开关；开启后维持原城生产服务、已签项目和已有军团，不接新的家庭或新城。没有20职业滑块、每餐配比、逐车发货或每日训练。

首次治理默认：允许普通建设及两周期民食保护；按均衡再投资40%；人口可在能力内增长；不授权野战军团、战争、新城或付费收藏。第一份木印也须主动选一次心愿，但可跳过、不影响粮食与建设。纯观看不是“不玩好”。

## 5.3 每30秒确定性规划

先读取同一revision的库存、已承诺任务、劳力、班次、床位、现金、未完成项目和真实消费预测。调度顺序小数字优先：
0 携货安全交付、危险设备收尾；10 当前/180秒内截止饭食；20 两周期保供、成熟主粮收割与必要灌溉；30 当前巡班、夜餐、已外出补给；40 住房安全、既有动物下一段、关键水木；50 已授权建设/街区/特色与军团维持；60 菜品、清扫、付费收藏；70 外部可选订单；90 研习；95 休闲。

同档按deadline→创建时间→orderID。已开始不可因重新排序强行中断；安全暂停后才可改岗。选worker：同工种且在可用班次→可安全改岗→能顺序自运的消费者。比较到任务节点最早到达时间、本工种加权属性A_job、agentID。不能为省路把被锁名将擅自撤官当挑夫。

建设候选按照01章资格产生。对每候选克隆试算采购、阶段物料、预算、目标容量和工人，全部合法才提交；不能试选三个方案就买三份材料。基础必要方案优先于特色/收藏。选中记录原方针、原负责人、受益需求、成本、前三个未选原因；只有完工事件才能写成果。

单次每城最多创建8个新父订单和32子订单，剩余下次处理。足够并发但不每次遍历2048×253×全图。所有去重键按consumerKey，按库存/设备/路线版本建立缓存，缓存命中不能改变确定性结果。

## 5.4 规划解释与自动处置

每城保留最近12条规划摘要；不为每袋粮发奏报。例：
“住宅区第2餐送达率88%，仓内粮足够。先调1位可空闲挑夫承担配送；若连续两窗仍迟到，再申请东坊配送点。工坊升级保持等待，不额外花钱。”

本次安排与更久的原计划区分；阈值不足给具体缺口，不用“AI正在思考”占位。原工作已取消时，记录取消与资源返回，而不是仍显示进行中。实际供应恢复无需主公确认。

主公不回复新策略卡，旧策略照常。议题最短间隔72小时、滚动7日≤2，未决最多3主题。卡片不是完成奖励；作决定时改变后续许可而非立即造资产。

## 5.5 重要人事：交接、旅行、到任一条计划

一城只设太守；有≥2城才允许建立一个都督辖区。都督由主公指定，必须在城、未锁定、可完成交接；他不兼太守或野战统帅。建立时明确cityIDs、talentIDs和可自动调任=true/false，默认主公确认后的辖区允许自动安排太守。

基础太守分B=floor(政治×0.5+智力×0.3+统率×0.2)，只用原始四维，装备不触发行政调任。都督候选参考分=floor(统率×0.4+政治×0.4+智力×0.2)；统帅参考分=floor(统率×0.6+武力×0.3+智力×0.1)，不取代玩家任命。

取消“安民荀彧+8”等按姓名加分。方针适配F按hero-system JSON中的policy_fit_job_weights_bp，计算候选作为太守对相关工种提供的主管属性＋适用work_rate_bp：F=floor(10×Σ方针工种权重×该工种加成/(10000×1700))，范围0—10；评估时用基础属性、L1，不读取装备。报价/巡逻/军事等非劳动效果在推荐面板另列，不暗加排名。最终太守候选分=B+F。所有候选一套公式；保供保护先于分数，低分代理照常能治理。

都督每43200秒评估一次。候选在talentIDs、不是都督/统帅、未锁定、无唯一物品出征锁、无正在进行的跨城计划。新候选分比目标现太守至少高8才考虑；上次自动调动距今≥259200秒。空闲候选优先。现任太守外调须有本地空闲代理，基础任用≥50且不已分配别处。没有就保留原职，不凭空生成代理。

对从另一城调太守的方案比较总分：目标与源城适配分之和至少增加8；处于supplyRecovery城市权重2，其余1。权重在计划创建时固化。否则不为“目标变好但源城严重倒退”而移动。人工任命可超越评分偏好，但仍不能绕过锁、旅程与身份唯一。

状态PROPOSED→SOURCE_HANDOFF→TRAVEL→TARGET_HANDOFF→COMPLETE。源交接120人工秒，到达后目标交接120人工秒。交接期间旧任仍生效；源交接完成同事务原人卸任、本地代理接任、创建旅程；在途无城市太守光环。抵达前目标原任继续；抵达且目标交接完成才原子换任。目标床和职位预留与计划ID绑定。

源/目标失效或被主公改任：尚未离开则安全取消；已在途先到目标作为闲居或沿原路返源，床位保证，不瞬移。原目标位被主公占用时不覆盖主公任命。取消不退款旅行时间或重复经验。旅行携带个人唯一装备锁到安全到达；装备不传送给其他人。

## 5.6 三城位置与交通

城市ID固定plain平川（初城）、stone青石、river临江。plain↔stone路程1200模拟秒，plain↔river900，stone↔river2100；方向双向同基准，每段开始固化，路网合作只作用后续段。跨城时间与本城地图点数独立，不能按屏幕像素计算。

居民、货、军团均有在途状态。跨城工作不会在两个城市重复计算供餐、人口或特性。在途常住人物按已装口粮供两餐/周期，从家中名单排除；餐ID跨城唯一，旅途中缺料在安全驿站等待，不再从两地自动各扣一次饭。

V5前不显示虚假的通用跨城生产；V5开启后使用与本地相同lot、reservation和carrier体系，不另建抽象“资源共享池”。

## 5.7 都督自动跨城调货

每300秒在辖内评估一次，优先缺口民食与必要投入，其次既有工程，再合法外贸。需求来自目的消费/生产订单，不是库存低于无限最大值。发送城扣除自己两周期居民、已有动物/軍团基础承诺和源任务预留后才有余量；目的地预留真实容量。

每城驿站1/2/3席，每份合同固定一位驿卒，基础装载12体积，未有板车时4体积。每趟只一种资源，货量为缺口、余量、载重与目标容量最小。装30工作秒＋去程＋卸30工作秒＋返程；脚夫本城搬到驿站的时间另算。公共道路服务费每趟2铜，本次创建时预留并在出发消费。不按运送粮食数发任务奖金。

双方同属势力无买卖收入，只有物理调拨和运费；跨城数据所有者仍是势力，用allocatedCity记录预算。出发后源不再可用，目的不到货不计可食；到货与返程分别事件，carrier返程前不可另接一趟。若同源同目的同resource已有未到货单，先扣其将到量再排缺口。

多城供应循环禁止：同lot不能在一周期内自动回到出发城；候选调运要求目的真实需求且两城预测净改善>0。转运链按原origin记录，不能把一次对内送达多次算贸易成就。

## 5.8 新城：逐车安置，而非到点赠送整城

V5实现两处固定机会，不无限生成城市。发现条件：初城人口≥32、近4餐C≥9500、驿站1，主公主动选择青石或临江。未批准不消耗、不倒计时过期。每城最多一次成功接纳，全球仍≤3城。

两地公共报价：现金800铜（勘察200、现场安置600）；材料原木48、木构12、石材16、器材4、食粮32、清水16。内含施工投入木40/木构12/石16/器材4，交接后保留木8/粮32/水16作为新城明确初始库存；不能再另复制一次开局600铜或64粮。

状态DISCOVERED→AUTHORIZED→SURVEY→DELIVERING→CONSTRUCTING→SETTLER_TRANSIT→HANDED_OVER。勘察驿卒60工作秒＋双向跨城路程，完成才开启site库存。此时消耗200铜；余600仍预留。项目现场容量只接本项目物料，上限为表中全部物料体积，不允许当无限通用仓。

材料从源城实际出库，按4/12体积多趟送达；无驿卒/车就排队，不画假车。施工材料齐备后允许派2名本城实际营造工，先交接旧任务、装足2周期旅途与施工口粮，再走真实路线。现场合计43200工作秒，按两人/班次实际贡献，沿四阶段耗材和余600铜。建造者仍是原有居民身份，在途/现场从家中餐名单排除，每周期吃2口粮；项目有独立营地餐容器。

主公授权此项目时同时确认口粮补给上限512人份、后续运输费上限120铜；这是最大可用额度，不一次扣除或白发口粮。低于下一2周期口粮时暂停施工，优先调已许可补给；预计补给不能在剩余口粮内到达，则两工人带返程口粮安全撤回，工程保留。补给恢复后可以再派，不借此扩大军团或永久征走人。不能拿无粮不死规则代替现实补给计算。

结构完成产生府署1、民居1、农庄1、粮仓1与公共灶/井/木作/碾米等开城包；其资产来源是上述一次工程包，不再次按01普通报价收费。之后8名外部志愿定居者（1代理太守＋7普通）以预先声明prospectID从区域入口300秒到城；人口与床位同时登记，不能复制源城8人。交接前不运行新城自动生产或生成无限后勤；交接后规则同普通城市，无第二份国库。

取消规则：勘察未开始全退；勘察已完成200不退；已送材料返源且实际耗时；施工已用部分不退；未到的定居者取消邀请不生成居民。已正式交接不可通过取消返款再重新造城刷人口。

青石采矿人工率+500基点、主粮作物净产不减，临江额外外部贸易合计额+8/期，平川新增居民住宅送餐容器每屋+4体积。禀赋只这些确定效果，不另给全部资源加成。均可通过一城路径获得核心收藏，多城不是核心收藏的强制门票。
