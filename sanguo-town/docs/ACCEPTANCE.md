# 附录E 验收矩阵与证据要求

全部应用验收初始为“未执行”。P0-R项目仅在现实联动扩展发布时为强制；核心版应明确标为未接入而非伪造通过。每条记录包括构建、设备／环境、配置哈希、存档夹具、操作、实际结果、日志与复测。
