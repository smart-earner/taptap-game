# 06A 四维、熟练度与星级技能
**PRD v0.9.0；30人逐人3技能及六模板见hero-town-v0.9.json。旧22技能仅历史引用，不与本版叠加。**
## A.1 三条独立成长
基础四维0..100取锁定旧目录；本版装备关闭，有效属性即基础属性。按20工种权重计算A_job=floor(Σ属性×权重/10000)。
熟练度按每300有效人工秒1XP，余秒保留，L1..5阈值0/60/180/360/600；走路/等待/表演不计，不自动改星级。
星级仅玩家消耗同名卡改变。每人恰3个不同技能，ID=heroID.s1/s2/s3，1/3/5星解锁，2/4星强化。星级不直接膨胀四维，不加全城永久光环。

## A.2 人工公式
本人=min(1000,max(0,A_job-50)×20)，熟练度=(L-1)×100；有效太守属性=min(500,max(0,A_job_prefect-50)×10)，无实际行政租约为0，自己不吃自己的主管。
适用本人技能合计≤1200bp；设施依现有合同。rate=clamp(10000+本人+熟练度+主管属性+技能+设施-可选低满意惩罚,8000,14000)。
workBP=baseSeconds×10000，阶段ceil(workBP/rate)；准备/收尾分别快照，被动等待不加速。20工种权重由JSON完整列出，无姓名条件分支。星级技能只允许self，不读取旧prefect技能来源。

## A.3 六模板，30人显式映射
每人s1在1星400bp，2星起600bp；s2在3星400bp，4星起600bp；s3为5星专长。相同工作同时匹配s1/s2可以相加但仍受1200上限。
|模板|s1作用工种|s2作用工种|5星s3|
|---|---|---|---|
|food|farmer/cook/server|farmer/cook|本人掌厨可制作丰盛素宴|
|supply|logger/miner|porter|本人采集木/石/铁/金矿石净产量+10%|
|craft|builder/carpenter/smith|restorer|本人主理新工程，木材成本-10%|
|logistics|porter/clerk/courier|server|本人本段搬运载量+25%|
|trade|clerk/handyman|porter/smith|本人准备金炉批次，木燃料-10%|
|guard|guard/handyman|logger/miner|实际完成晚巡后本周期环境+5|
基础设施和生存配方不依赖任一特定人或高星。首批用共享机制模板但独立人物/技能名称/造型；不宣称30种完全不同经济机制。解锁卡显示该人当前实际生效的能力，未解锁明确下一星条件。

## A.4 专长精确结算
丰盛素宴cook_feast：grain1500+wood500→meal4000，hearty质量100，45/45/10秒。仅实际5星food厨师可准备/收尾；被动期可离开，缺合格收尾者等待或由原人下一班继续。无免费肉料、无需养殖前置，菜单缺料退basic。
采集增产：批次开始锁执行者/星级，输出floor(base_mU×11000/10000)，必须预留完整增后容量。树4木变4.4，金矿2矿变2.2；不加冶炼产出、不加金币入库汇率。转人工/换人不重选快照或复制产出。
节材：新工程授权报价时绑定一个真实5星craft主理者，先完成30秒现场勘测（builder人工），才启用报价木材ceil(base_mU×9000/10000)。主理者可随后做其他工作；同项目只一份折扣，不追溯已授权工程。不得仅拥有角色就自动减价。4段按折后总量分配，剩余材料不是补发收益。
载量：路段装货预留时snapshot，肩挑4→5体积、板车12→15；步速/装卸基础工时不变；至少容纳实际满载货，升星后不能对已装货追加瞬移货。
省燃料：本人准备smelt_gold时wood500→450mU，矿石/产物不变，完整输入检查用折后量，不能事后退料。
晚巡环境：完成真实120秒晚巡且合法返家后有效，本周期末清零；同城取最大5，不按人数累加，不增金币或产量。满足8人和班次条件才排巡线，5星不能创造假任务刷环境。
所有专长仅实际相应任务可触发；不支持玩家手动放技、随机暴击/额外掷骰、材料书、重复技能升级。

## A.5 快照与解释
每阶段保存contentHash/heroID/star/skillID/metric/value/retainedValue/eventID；重放只使用旧快照。UI分项展示属性、熟练度、行政、星技、设施与上限裁剪；满上限强化后显示受限，不假报收益。
1星厨师A=50无主管：s1=400，则准备ceil(30/1.04)=29、被动30、收尾ceil(10/1.04)=10，总69秒。3星food同工种s1+s2=1000，总28+30+10=68；资源与4饭输出不变。
金矿无属性/熟练/主管时2矿/60秒；5星supply s1矿工600，采集工时ceil(60/1.06)=57，产矿2200mU。单独产量效果不会再缩时间。该向量不代表包括搬运、炉子和休息的金币速率。
禁止复用旧库drill/escort等无当前触发入口的效果当作新星技；新机制必须实现上述六个原语并通过运行用例，静态配置存在不算已实现。
