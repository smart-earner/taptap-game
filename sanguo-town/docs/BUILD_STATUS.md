# 当前编码状态｜visual-0.2

人物表现已接入Mac客户端；模拟规则仍为core-0.1，存档schema没有变更。不是完整游戏。

## 本批已实现

| 模块 | 实际边界 |
| --- | --- |
| 人物造型 | 三种原创2D分层矢量人物：文官、武将、工匠；不是3D或商业级逐帧素材 |
| 动作 | 待机、行走、读简、挥锤、搬运、耕作、伐木、挥击八种简易姿态 |
| 行为 | 路点行走、转向、工作、返回、脚底深度排序、前景树木遮挡 |
| 城景 | 读取真实居城、当前岗位与产能；岗位居民是明确标注的表现代表 |
| 动作样板 | 独立演示，不读写存档；长枪／佩剑切换仅试装，不发放收藏 |
| Mac适配 | SpriteKit节点复用、SwiftUI入口、可见性暂停、系统减少动态效果 |
| 预览导出 | 同源Swift生成36秒HTML动画与SVG姿态表，无外部网络请求 |

## 原核心已实现

唯一国库与分城库存、五维人物与职业经验、幂等命令与权限校验、太守按方针调岗、同城太守任用、基础生产、七天离线边界、三个存档备份与损坏拒绝。原core-0.1的细节与历史测试记录保留在Git历史和core-test-report.json。

## 尚未实现

骑乘／马匹骨架、完整战斗命中和名将独有造型；收藏装备实际读写、培养树与研习；自主建造升级、精确项目材料预留、完整周期财政、跨城物流与调任、军团战役、十张决策卡、全部常驻收藏路径、按键与行情联动。
