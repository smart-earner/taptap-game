# 原生视觉改版 · 2026-09-21

本轮是SpriteKit/SwiftUI矢量视觉升级，不是真3D建模，也不代表完整专业美术已验收。原生应用已重新编译并打开。

## 已改

- 暖纸色/青绿配色、左侧导航、宋体标题；小城、招募、培养、记录及揭晓统一样式。资源保留小提示，不恢复大型资源面板。
- 30个heroID有显式造型参数，冠帽/胡须/甲片/体型与配色组合；共享原动作骨架。卡片直接使用城中同一矢量人物，不以系统人像图标代替。
- 日夜地图、河岸、树冠、田垄、井亭、金矿、炉台、道路铺面、建筑立面细节。
- 住宅真实houseLevels驱动1/2/3阶外观，分别增加回廊/楼层；施工阶段驱动物料堆/梁架/墙体/屋顶，升级显示脚手架。
- 场景按元素缓存，变化时替换相应节点，避免每次快照重建所有静态树木与道路。没有据此宣称能耗验收通过。

## 边界

- 未修改引擎、概率、产量、任务、保存格式或玩家资产；默认进入小城，点击人物查看培养。
- 原生SpriteKit视图仍保留历史布局；Godot正式视图已迁移到PRD layout6，按18地块、4×5主路网、24田位和独立住宅节点投影。两层均只读取LifeMap/正式地块状态，不修改经济路径。
- 道路这次是外观优化，没有新增道路升级规则/加速。非住宅建筑目前没有独立持久等级，不能用建筑数量冒充等级。
- 人物仍为分层矢量骨架，非Blender模型；共享模板仍明显，后续可用专门建模/绘画资产替换，先做少量质量样板再铺满30人。
